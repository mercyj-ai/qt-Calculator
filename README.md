C++ Scientific Calculator

A console-based scientific calculator built with C++ as part of my journey to learning C++ and exploring scientific computing.

Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Powers and square roots
- Trigonometric functions: sine, cosine, and tangent
- Trigonometric calculations using degrees
- Base-10 logarithms
- Input validation for invalid numeric input
- Division-by-zero handling
- Repeated calculations until the user chooses to quit

Technologies Used

- C++
- Standard C++ libraries: "<iostream>", "<cmath>", and "<limits>"
- Qt Creator
- MinGW compiler

How to Run

1. Clone this repository:
   
   git clone YOUR_REPOSITORY_URL

2. Open the project in Qt Creator, or compile the source file using a C++ compiler.

3. Run the program and follow the console prompts to perform calculations.
